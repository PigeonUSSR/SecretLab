\# C Language Research Project



Проект исследует язык C и Unix (1969–1989), показывая, как C сделал системное ПО переносимым.



\## Структура

\- `index.html` — готовая страница в стиле терминала Unix.

\- `research.md` — связная история C (\~3 страницы).

\- `era.md` — исторический контекст и визуальные ориентиры.

\- `concept.md` — концепция, аудитория, обещание курсов.

\- `sources.md` — источники с подтверждениями и расхождениями.

\- `PROMPT.md` — промпт для агента с ограничениями.

\- `iterations.md` — отчёт по итерациям.

\- `visual-references.md` — 15 визуальных ориентиров.

\- `blocks/` — отдельные блоки для сборки страницы.

\- `assets/css/style.css` — стили.



\## Как опубликовать

1\. Загрузи файлы в репозиторий GitHub в ветку `main`.

2\. В настройках репозитория: Settings → Pages → Source: `main` / root.

3\. Получишь две ссылки: на репозиторий и на сайт GitHub Pages.
